# Clarity Space — разбор после тестирования

> Протестировано вживую 2026-10-01: зарегистрировал тестовый аккаунт, прошёл
> онбординг, создал проект/задачи, проверил AI-чат, Канбан, Таймлайн, Совет,
> привычки, цели, дневник, мобильную версию и изоляцию данных между двумя
> аккаунтами. Ниже — что оставить, что добавить, что убрать и что починить.

## Что это сейчас
AI-трекер для предпринимателей. Уже очень насыщенный продукт: **18 разделов** —
Kanban, Таймлайн, Проекты, Гант, AI-Чат, Совет директоров, Договорённости,
Встречи, Транскрипция, Люди (CRM), Календарь, Брифинг, Цели/BHAG, Документы,
Дневник, Привычки, Дашборд, Статистика.
Интеграции: Google/Яндекс Календарь, Todoist, Telegram-бот, виджет iPhone
(Scriptable), упор на Obsidian. Тариф Free (50 AI-сообщений/день), Pro Max «скоро».
Стек: React + Vite PWA, REST API `/v1/*`, PostgreSQL (есть полнотекстовый
`search_vector`), JWT, Telegram WebApp SDK.

## Что работает хорошо — не трогать
- **Визуал ровный и приятный**, единый стиль, адаптив ок: на телефоне снизу
  таб-бар (Таймлайн / Привычки / AI-Чат / Календарь / Ещё) — это правильно.
- **AI-чат реально делает действия**, а не только болтает: по тексту создал
  задачу с датой/приоритетом/проектом, перенёс другую, поставил приоритет.
- **Богатая модель задачи**: статус, приоритет (1–5), срочность (1–5), влияние
  на выручку, повторение, зависимости, подзадачи, метки, люди.
- **Изоляция данных между аккаунтами на уровне API работает**: со второго
  аккаунта чужие задача/проект отдают `404`, свой список пуст. Для
  многопользовательского режима это главное, и базово оно есть.
- **HTML в названии задачи экранируется** (вставил `<b>…</b>` — отрисовался как
  текст), то есть явной stored-XSS в этом месте нет.

---

## ⚠️ Главная проблема: продукт перегружен
18 разделов для личного трекера — это очень много. Часть функций пересекается и
размывает фокус («мухи и котлеты» в твоих же словах):
- **Kanban + Таймлайн + Гант + Календарь + Дашборд + Брифинг** — это 6 способов
  посмотреть на одни и те же задачи. Для одного пользователя хватит 2–3.
- **Совет директоров (24 ИИ-персоны)** — яркая, но нишевая игрушка. Легко
  раздувает ожидания и поддержку, редко используется ежедневно.
- **Документы + Дневник + Obsidian** — три места для текста/заметок.

Рекомендация: определить **1–2 «ядровых» сценария в день** (скорее всего:
AI-чат как вход + один вид задач + привычки) и всё остальное свернуть в
«Ещё» / настройки, включаемое по желанию. Меньше поверхностей → выше качество
каждой и проще поддержка, особенно перед многопользовательским запуском.

## Что добавить

**Для себя (личный трекер):**
1. **Быстрый ввод из любого места** — глобальный «+» и уже есть `Ctrl+K`; довести
   до «ввёл одной строкой → AI разложил по проекту/дате/приоритету». Это и есть
   твой «второй мозг».
2. **Напоминания и дедлайны с нотификациями** (через Telegram-бот и PWA push) —
   сейчас задачи с датой есть, активных напоминаний в вебе не видно.
3. **Повторяющиеся задачи видимо в UI** — поле `recurrence` в модели есть,
   показать его работу (серии, пропуск, перенос).
4. **Инбокс/быстрый захват без выбора проекта** — единая точка «скинул и забыл»,
   потом разбор. Ты сам про это говорил в идее второго мозга.
5. **Тёмная тема** — для ежедневного инструмента почти обязательна.
6. **Полнотекстовый поиск по всему** (задачи, встречи, документы, люди) — БД это
   уже умеет (`search_vector`), вынести в `Ctrl+K`.

**Для многопользовательского режима (позже):**
7. **Команды/рабочие пространства**: назначение исполнителей (поле `assignee`),
   общие проекты, роли (owner/member/viewer). Сейчас всё строго персональное.
8. **Шаринг и комментарии** на задачах между пользователями.
9. **Биллинг** (Pro Max «скоро») — лимиты AI уже считаются (`AI: 0/50`), нужна
   оплата и тарифные ограничения на бэке.

---

## Что убрать / свернуть
- **Совет директоров** — в отдельный «лаб»-раздел или фича-флаг, не в основное меню.
- **Дублирующие виды задач** — оставить Kanban + Календарь (или Таймлайн),
  Гант включать только для проектов с датами.
- **Дневник vs Документы** — объединить «текстовые» сущности, чтобы не было трёх
  мест для заметок.

## 🐞 Баги и шероховатости (нашёл при тесте)
1. **Дата в форме задачи — американский формат `mm/dd/yyyy`** при русской локали.
   Нужен `дд.мм.гггг`.
2. **Валидация пароля — минимум 6 символов и системное сообщение на английском**
   («Please lengthen this text to 6 characters…»). Для мультипользователя слабо
   и не локализовано. Поднять минимум, добавить проверку сложности, своё
   сообщение.
3. **Нет подтверждения email** при регистрации. Для себя ок, для многих
   пользователей — спам/фейки/восстановление доступа. Нужно до публичного запуска.
4. **AI показывает внутренние ID** («Задача #416 обновлена», «#418») — техническая
   утечка, пользователю не нужна.
5. **401 в консоли на публичных страницах** (лендинг/логин дёргают авторизованные
   эндпоинты до входа) — не критично, но шумит в логах и замедляет первый экран.
6. **JWT лежит в `localStorage` со сроком ~30 дней.** Крадётся через XSS и не
   отзывается. Для многопользовательского режима лучше `httpOnly`-cookie +
   короткий access + refresh-токен. (Сейчас критичных XSS я не нашёл, но
   поверхность большая — 18 разделов с пользовательским вводом.)
7. **Последовательные числовые ID** (user 10→11, task 418). IDOR я проверил —
   защита есть (404 на чужое). Но стоит держать это в тестах регрессии: любой
   новый эндпоинт обязан фильтровать по `user_id`.

## Безопасность перед многопользовательским запуском (чек-лист)
- [ ] Автотест «пользователь B не видит/не меняет объекты пользователя A» на
      **каждый** эндпоинт (`/v1/tasks`, `/projects`, `/meetings`, `/people`,
      `/documents`, `/habits`, `/goals`, `/journal`…).
- [ ] Подтверждение email + сброс пароля + сильные пароли + rate-limit на логин.
- [ ] Токены: httpOnly-cookie + refresh, возможность разлогинить все сессии.
- [ ] Лимиты и биллинг на бэке (не только в UI).
- [ ] Логирование действий и резервные копии БД.
- [ ] Политика хранения транскрипций/записей встреч (чувствительные данные).

## Связь с идеей «второго мозга»
Clarity Space уже закрывает **трекерную** половину той задачи (задачи, цели,
привычки, встречи, люди) и даже имеет AI-чат с действиями. Чего ему не хватает
до «второго мозга» из прошлого обсуждения — это **хранилище произвольных файлов
с умным поиском** (скинул что угодно → нашёл по смыслу). Логичный путь: не
плодить второй продукт, а усилить здесь разделы **Документы + Транскрипция +
поиск** до полноценной базы знаний. Тогда Clarity Space = трекер + второй мозг
в одном.

## Приоритеты (мой порядок)
1. Починить мелочь, которая бьёт по доверию: формат даты, локализация, скрытие
   внутренних ID (1 день).
2. Упростить меню до ядра, остальное — в «Ещё» (0.5 дня, большой эффект).
3. Безопасность токенов + email-подтверждение + изоляционные автотесты — до
   приглашения других людей.
4. Тёмная тема, напоминания, единый быстрый захват/инбокс — для ежедневного удобства.
5. Команды/исполнители/роли — когда перейдёшь к многопользовательскому.
