# Второй мозг

Личная база знаний на своём сервере: сюда отправляются все файлы, заметки,
документы и голосовые, а спрашивать и общаться можно через приложение Claude
(web, Desktop, iOS, Android, в том числе голосом) — по подписке, без оплаты
за токены.

**Суть:** «мозг» (хранилище + умный поиск) работает как MCP‑сервер и подключается
к Claude как custom connector. Захват — через Telegram‑бота, веб‑загрузку,
e‑mail и синхронизируемую папку.

📐 Архитектура, стек, лучшие практики и план: [docs/architecture.md](docs/architecture.md)
